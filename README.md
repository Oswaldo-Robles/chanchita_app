# Chanchita 🐷

App móvil (React Native + Expo + TypeScript) para dividir los gastos de una salida entre amigos y cobrar por WhatsApp con un toque.

> Estado: MVP en construcción. Este README se completará en la entrega (capturas, APK e instrucciones de instalación).

## Cómo correr el proyecto

```bash
npm install
npx expo start      # abre la app en Expo Go
npm test            # pruebas unitarias (Jest)
npm run typecheck   # TypeScript
```
